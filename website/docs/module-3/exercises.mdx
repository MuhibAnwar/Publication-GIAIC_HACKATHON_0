## Exercise 1: Basic IMU Data Processing

**Problem Statement:** Implement a ROS2 node that reads IMU data and calculates the orientation (roll, pitch, yaw) from the accelerometer and gyroscope readings.

**Learning Objectives:**
- Understand IMU data formats in ROS2
- Implement basic orientation calculations
- Handle sensor data streams

**Specifications:**
- Subscribe to `/imu/data` topic with `sensor_msgs/Imu` message type
- Calculate roll and pitch from accelerometer data
- Implement simple gyroscope integration for yaw
- Publish orientation as quaternion

**Test Cases:**
- When IMU is level: roll and pitch should be ~0
- When IMU is tilted: appropriate changes in roll/pitch
- Consistent quaternion representation

**Hints:**
- Use `tf.transformations` for quaternion operations
- Apply low-pass filtering to reduce noise
